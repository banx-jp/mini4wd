#### MEシャーシ（ライザン）：直付けスピード特化仕様【優先】
アドバンスパックの「ライトダッシュPRO」や「キャップスクリュー」「スーパーハードタイヤ」を全投入し、直付けの速さを最大限まで引き出す構成です。
* シャーシ・ボディ: ライザン（MEシャーシ）
* モーター: ライトダッシュモーターPRO（アドバンスパックより流用）
* ギヤ: ハイスピードEXギヤ（3.7:1）またはキット付属超速ギヤ（3.5:1）
* 足回り: スーパーハード小径ローハイトタイヤ ＋ レッドホイール（ネロより流用）
* フロント:
  * ステー: 95186 HG カーボンフロントワイドステー (1.5mm) J-CUP 2026
  * ローラー: 15398 2段アルミローラーセット (13-12mm)
  * ビス: 皿ビス加工（74130）を実施
* リヤ:
  * ステー: 95187 HG カーボンマルチワイドリヤステー (1.5mm) J-CUP 2026
  * ブレーキ: 15550 HG カーボンブレーキステー (1.5mm)
  * ローラー固定: キャップスクリュー（25mm/30mm）（ネロより流用して曲がりを防止）
  * ローラー: ※足りないパーツ（後述）
* 制振: 15501 スリムマスダンパー ＋ ネロ付属スリムマスダンパー（1.5g）

* シャーシ・ボディ: グレートマグナムR または コスモソニック（FM-A）
* フロント: 15469 フロントスライドダンパー ＋ 15548 HG カーボンフロントワイドプレート (2mm)
* リヤ: 15467 リヤスライドダンパー ＋ 15549 HG カーボンリヤワイドプレート (2mm)
* ブレーキ: 15550 HG カーボンブレーキステー (1.5mm)

### 不足パーツ（購入リスト）
ストッククラスレギュレーションへの適合と、2台を完成させるために買い足しが必要なアイテムです。

#### MEシャーシ用（優先）
* リヤローラー: 19mm オールアルミベアリングローラー（1セット）
* 軸受けベアリング: HG 丸穴ボールベアリング（4個入り・1セット）※駆動系のスピードを引き切るために強く推奨
* 固定パーツ: ステンレス皿ビスセット（下面のフラット化用）

#### FM-Aシャーシ用
* 片軸モーター: ハイパーダッシュ3モーター または ライトダッシュモーター
* ローラー: 13mmオールアルミベアリングローラー など（前後スラダン用として2セット）

#### 共通消耗品
* 2mmロックナット（走走時のナット緩み・脱落防止用）
